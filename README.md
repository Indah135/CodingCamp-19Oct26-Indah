# 🗓️ Life Dashboard

A clean and minimalist personal productivity dashboard that runs entirely in the browser — no backend, no framework, no dependencies.

## ✨ Features

- **🕐 Clock & Greeting** — Live clock with date in Bahasa Indonesia and time-based greetings (Pagi / Siang / Sore / Malam)
- **👤 Custom Name** — Personalized greeting with your name, saved in Local Storage
- **⏱️ Focus Timer** — 25-minute Pomodoro timer with Start, Pause, and Reset controls, animated SVG progress ring, and browser notification on completion
- **✅ To-Do List** — Add, edit (inline), complete, and delete tasks with duplicate prevention
- **🔗 Quick Links** — Save and access your favorite sites in one click, with auto-fetched favicons
- **🌙 Dark / Light Mode** — Toggle with system preference detection, saved in Local Storage

## 🛠️ Tech Stack

- Pure **HTML**, **CSS**, and **JavaScript** — no React, Vue, or any framework
- All data persisted in **Local Storage**
- Works in all modern browsers (Chrome, Firefox, Edge, Safari)
